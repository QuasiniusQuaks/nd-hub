# ND-Hub React Frontend (Islands)

This project provides an incremental Vite + React foundation for ND-Hub Web.

## Commands

- `npm install`
- `npm run dev`
- `npm run build`

## Build output

The Vite build outputs static assets to:

- `../backend/web/react/ndhub-react.js`
- `../backend/web/react/ndhub-react.css`

The legacy UI remains available and can continue to render fallback tables when no island is mounted.
