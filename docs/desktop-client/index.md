# Desktop Client

Der ND-Hub Desktop Client ist eine PySide6-basierte Anwendung fuer den
lokalen Arbeitsplatz. Er deckt alle Kernprozesse fuer Notfalldepots
abdeckend in einer modernen, performanten UI ab und kann optional ueber
Hybrid-Sync mit der Webanwendung verbunden werden.
