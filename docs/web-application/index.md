# Webanwendung

Die ND-Hub Webanwendung ist eine zentrale, browserbasierte
Bereitstellung der ND-Hub-Plattform. Sie besteht aus einem
**FastAPI-Backend** und einem **React/Vite-Frontend** und wird ueber
**Docker Compose** (mit MariaDB) betrieben.
