# Release Notes (Short)

## Deutsch

- Desktop/Web-Paritaet fuer Kernfluesse auf produktionsnahen Stand gebracht.
- Bewegungsverlauf gehaertet (Filter-Paritaet, Persistenz, CSV-Export, Attachment-UX).
- Import gehaertet (idempotent via Fingerprint, Dry-Run, Fehlerklassifizierung).
- E-Mail-Flow erweitert (Draft-Fallback plus optionaler SMTP-Liveversand).

## English

- Desktop/Web parity for core workflows reached a production-near level.
- Movement history hardened (filter parity, persistence, CSV export, attachment UX).
- Import flow hardened (fingerprint-based idempotency, dry-run, error categorization).
- E-mail flow extended (draft fallback plus optional SMTP live delivery).
- Backup/restore hardened (size limits, format validation, improved audit metadata).
- Report exports hardened (date validation, context-rich filenames).
- User admin safeguards extended (self-protection, last active admin protection).
- Stability/acceptance regression completed successfully: **28 passed**.
